# Stock Trading Platform - CodeAlpha Internship

A Java-based simulation of a Stock Trading Platform developed during the CodeAlpha Internship.

## Features
- View Market Data with stock prices.
- Buy and Sell stocks dynamically.
- Track Portfolio performance and available balance.
- View transaction history.

## How to Run
1. Compile the program: javac StockTradingPlatform.java
2. Run the program: java StockTradingPlatform
